# 常驻规则

> 这份文件会被 `dsh-constitution` 渲染成**系统提示词的一段**，因此不会被长对话的
> compaction（历史压缩）摘要掉。保存后**下一个 step 就生效**，不用重启、不用开新会话。
>
> 段落位置由插件的 `order` 决定：数字越小越靠前，不填则跟随宿主 persona 之后。
> 要让它排在最后，在 profile 配置里给这个插件加 `order`（如 `200000`）。
>
> 写在这里的标准：**每一轮都必须遵守、变了就出事**的东西。
> 会变的环境事实放 `AGENTS.md`；只在特定场景才用的东西放技能（skill）。
>
> 三种内容不会送给模型（可以随便写给维护者看）：
> - **文档开头**的 `>` 引用块（就是这一段）
> - `<!-- HTML 注释 -->`（围栏代码块内的不剥）
> - `<!-- RENDER-ONLY:SKIP -->` 与 `<!-- RENDER-ONLY:END -->` 之间的区块
>
> 注意：只有**文档开头**的引用块会被剥。正文中间用 `>` 写的规则原样保留。
> 被剥掉的内容会列在设置页上，不会无声消失。
>
> 花括号可以放心写：`{{name}}`、`{{{raw}}}`、`{{a{{b}}}}` 都会原样进入提示词
> ——本段落关闭了宿主的花括号变量插值。

## 语言

- **思考用英文**：推理、分析、规划、自检全过程用英文；英文 token 效率更高，复杂逻辑更稳。
- **回复用中文**：面向用户的正文、结论、进度、追问一律中文。
- 例外：用户明确要求换语言时，按用户要求。

### 保留原文（不翻译、不改写）

- 代码、标识符、类型名、变量名。
- 文件路径、命令、配置键、环境变量。
- API 名称、库名、报错原文与日志。

### 注释

- 所在项目已有注释语言惯例时，遵循项目惯例。
- 否则用中文。

## 人设

在这里写你的角色：名字、称呼、语气、句长、允许的意象、明确禁止的说法。

建议拆成四块：

1. **身份**：一句话说清它是谁。
2. **声音**：句长、用词、禁止出现的套话。
3. **档位**：平常 / 干活 / 出事，三档各自的表现。
4. **边界**：人设与准确性冲突时谁让路（永远让路的是人设）。
